🧠壹、為什麼老師需要 Skills？📖 前言
😩
老師的痛點：每次都要重新上傳、重新打一遍
過去，每次想請 AI 幫忙，都得先貼上晨會通知、再貼上課文或影片連結、然後打一大段說明……一個步驟都不能少。有了 Skills（技能），只要設定一次——不用再一個一個上傳資料，也不用再重新打字，下次輸入一個斜線 /，AI 立刻依你設定好的方式動作。

⏱️ 省下重複勞動設定一次，終身享用

  • 把「整理晨會重點」「課文心智圖」「活動海報」這類常用任務存成技能卡，下次一鍵呼叫
  • 不用每次重新解釋你要什麼，AI 記得你的習慣
  • 一個老師帳號可以存多張技能，不同角色（導師、科任、召集人）各自設定

🔒 學生資料不外流Chrome 原生，最安心

  • Chrome 內建功能，不需要安裝任何第三方外掛或 App
  • 學生評語、個人資料、晨會與班級資訊等敏感內容，不會傳給來路不明的服務
  • 連線 @Google Workspace 直接讀取雲端資料，不用手動上傳

🔑 兩個必學的操作會這兩招就夠了

  • / 叫出技能：在任何網頁輸入斜線，選你存好的技能，AI 依設定立刻執行——不用再打那一大段說明
  • @ 指定資料來源：告訴 AI 去讀哪裡——@Google Workspace 抓雲端資料、@YouTube 拆解影片，也能直接讀「你正在看的當前網頁」，甚至用 @ 把其他分頁也加進來一起讀（例如比較多支影片）——全都不用手動上傳檔案
🛠️貳、開始之前：六步驟設定好 Chrome Skills

研習開場先把環境設定好。跟著六個步驟——登入、連線 Google、開啟 Skills、建立技能卡，最後附上開不出來時的地區解法。全部設定完成，再進入實戰。

1

登入 Chrome（Google 帳號）

  1. 打開 Chrome 瀏覽器，點右上角頭像圖示
  2. 用你的 Google 帳號登入（學校或個人帳號皆可）
  3. 建議用平常存 Google 雲端資料的那個帳號——登入後才有 Gemini 與後續 @Google Workspace 功能
💡 只記得帳號前面、忘了後綴？對照一下格式：
個人xxxx@gmail.com
學校xxxx@go.edu.tw
2

連線 Google 服務

  1. 網址列輸入 chrome://settings/ai/gemini 後按 Enter
  2. 開啟右側各項開關，解鎖 @Google Workspace @YouTube @Gmail @Google 日曆 @Google 雲端硬碟
  3. 連好後，AI 可直接讀取你的 Google 資料，不用再手動上傳檔案
3

開啟 Skills 實驗功能

  1. 網址列輸入 chrome://flags 後按 Enter
  2. 搜尋框輸入「Skills」
  3. 下拉選單從 Default 改成 Enabled
  4. 點右下角 Relaunch 重啟瀏覽器
4

建立個人化技能

  1. 在側邊欄輸入欄打「/」，選「＋ 加入技能」
  2. 填技能名稱與指令內容（你的 Prompt）→ 按儲存
  3. 另一招：先送出一段提示詞，點左側閃電圖示「儲存為技能」
  4. 之後在任何網頁打「/」就能呼叫
5

在網頁中呼叫技能

  1. 前往想分析的網頁
  2. 點右上角「問問 Gemini」或用快速鍵打開側邊欄
  3. 選擇技能，一鍵套用！
6

開不出 Skills？地區解法

  1. 若 chrome://flags 找不到 Skills，多半是地區限制（功能先對美國開放）
  2. 先完全關閉 Chrome，按 Win 鍵 ＋ R，貼上下面這行 → Enter，用「美國地區」重開
  3. 重開後再回 chrome://flags 找 Skills
"C:\Program Files\Google\Chrome\Application\chrome.exe" --variations-override-country=us

※ 若沒反應，Chrome 可能裝在 Program Files (x86)；把路徑換成 C:\Program Files (x86)\Google\Chrome\Application\chrome.exe 再試一次。

・適時加入示意圖、icon 或簡單資訊圖表輔助說明，圖文平衡。插圖一律用簡單、扁平的「向量圖示／SVG 風格」（線條乾淨的 icon、幾何圖形），不要寫實人物、不要真實照片、不要任何品牌或卡通／名人角色（避免版權與不相關圖片）。可參考可愛日式扁平插畫的簡潔感，整份風格一致。

・所有中文務必用可正常顯示的系統字體「打字呈現」，絕對不要把中文做成圖片或藝術字——那常會變成亂碼、黑方塊或缺字。
・標題與內文都要清楚、完整、不缺字；若某字無法正常顯示，請換字或改用文字方塊重打。
・整體風格：簡潔、現代、對比清楚〔可指定：教育活潑／商務專業／文青手感〕。

📖 EzType 使用說明（點開）

EzType 讓你「按住快捷鍵說話、放開就自動把整理好的繁體中文打到游標位置」。

■ 第一次使用

  1. 雙擊「EzType.exe」啟動。
    ※ 若跳出 Windows「不明發行者」警告：點「更多資訊」→「仍要執行」（這是未簽章自製程式的正常提醒，不是病毒）。
  2. 第一次會自動開啟設定視窗，先申請免費金鑰：點上方「免費申請 Groq 金鑰（教學）」→ 把 gsk_ 開頭的金鑰貼到「Groq 金鑰」欄 → 可按「測試金鑰」確認 → 按「儲存」。

■ 日常使用

  1. 把游標點進任何可打字的地方（記事本、Word、聊天、瀏覽器…）。
  2. 按住快捷鍵（預設「右 Ctrl」），清楚說一句話。
  3. 放開快捷鍵 → 約 1～2 秒，文字就自動出現（開始會有「嘀-嘟」提示音）。

■ 桌面小夥伴

右下角小角色顯示狀態：待命 → 聆聽中 → 辨識中。右鍵叫出選單（開啟設定／結束程式），可滑鼠拖曳位置。

■ 潤飾風格（辨識後 AI 怎麼整理你的話）

四種風格，改寫程度：只修錯字 < 自然口語 < 正式書面 < 精簡重點

  • 只修錯字：最忠實，只修聽錯的字、加標點。
  • 自然口語（預設）：去掉「嗯、呃、那個」等贅詞，通順但保留口語感。日常聊天、筆記最好用。
  • 正式書面：改寫成正式專業書面語。公文、報告、email。
  • 精簡重點：濃縮成重點、最短。待辦、摘要。

例：你說「呃…那個，明天會議可能要改時間，早上大家好像有事，改下午三點好不好」
→ 自然口語：明天會議改一下時間，早上大家好像有事，改下午三點好嗎？
→ 正式書面：明天的會議建議調整時間，因上午多數同仁另有安排，建議改至下午三點，是否方便？
→ 精簡重點：明天會議改下午三點（上午大家有事）。

■ 防毒軟體警告？（重要）

部分防毒可能對 EzType.exe 跳警告甚至誤刪，這是誤判：① PyInstaller 打包的啟動碼與某些惡意程式相似，行為偵測較敏感；② 未做付費程式碼簽章，被視為不明發行者；③ 語音輸入本來就需要「監聽快捷鍵、模擬鍵盤貼上、讀寫剪貼簿」，看起來可疑但是功能必需。

本程式是安全的：原始碼完全公開（開源 GPL-3.0），無病毒／後門／廣告／追蹤；只會以 HTTPS 連到你選的 Groq 服務（api.groq.com）做辨識；金鑰只存在你自己電腦，不外流。若被擋下，可把 EzType 資料夾加入防毒「白名單／例外」，或上傳 VirusTotal 查驗（少數引擎誤報屬正常）。

■ 常見問題

Q：說話後沒出字？確認麥克風沒靜音、游標有點進輸入框；顯示「我聽不清楚」＝沒收到聲音，請大聲一點、靠近麥克風；跳「金鑰無效／連不上」＝開設定檢查金鑰與網路。

Q：按快捷鍵跳出「檔案／編輯」選單？你把快捷鍵設成 Alt 了。Alt 在 Windows 會開選單，請改用「右 Ctrl」、「F8」或「Caps Lock」。

Q：金鑰會被別人用到嗎？不會。金鑰存在你自己的 %APPDATA%\EzType，分享出去的 zip 不含任何金鑰，每個人各填自己的。

■ 隱私

語音與文字只會以 HTTPS 傳給你選的 Groq 服務做辨識，不傳到其他地方，也沒有追蹤。
